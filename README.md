# Growvera Digital

Responsive static digital marketing website for Growvera Digital, Surat. Black background with a lime-to-mint gradient, original typography-led layouts, six services, about, approach, insights, contact and privacy pages.

## Preview

Node.js 18 or newer. No packages to install.

```sh
npm run build
npm start
```

Open http://127.0.0.1:4173. Alternatively open index.html directly, or use VS Code Live Server.

## Edit

Edit page content in `build.mjs`, styles in `styles.css` and browser interactions in `app.js`. Run `npm run build` after editing content. Generated HTML files are committed so the website works on static hosts, including GitHub Pages. Use `npm run check` to verify pages and internal links.

## GitHub

Save in VS Code, commit the desired files and push to origin/main. Saving a file alone does not upload it to GitHub. This repository is private; storing code on GitHub does not automatically publish a website. Configure an appropriate static hosting service when ready to go live. No hosting deployment is configured by this project.
